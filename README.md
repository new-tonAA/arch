# 《窗》THE WINDOW — archive

A 112-second history of architecture, made entirely in code:
seven visual languages, one continuous film, transitions built from
architectural elements (a doorway, lead cames, a drawing sheet, a grid,
a knife cut, a point cloud).

Seven eras, seven languages:

| Era | Language |
|---|---|
| 5th c. BCE stone | copperplate engraving |
| 12th–13th c. Gothic | stained glass |
| 1435 Renaissance | pen-and-wash perspective |
| 1851 iron & glass | cyanotype blueprint |
| 1920s modernism | Swiss motion graphics |
| 1970s–80s postmodern | Memphis diorama |
| now | LiDAR point cloud |

Every frame is Canvas 2D code. The score and foley are synthesized from
scratch; the Mandarin narration uses gTTS. No stock footage, no video model.
